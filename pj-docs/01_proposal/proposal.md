## 1. 背景・目的

- 中小規模チームにおいて、タスク管理がExcelやチャットツールに分散し、進捗の可視化ができていない。
- チームの生産性向上とプロジェクト進捗の可視化を目的とした、シンプルなタスク管理Webサービスを新規開発する。

## 3. サービス概要

- タスクの作成・割当・進捗管理・レポート出力ができるSaaS型Webサービス。
- Webブラウザから利用可能（PC/タブレット対応、将来的にモバイルアプリも検討）。

## 4. ターゲットユーザー

| ペルソナ | 課題 | 期待効果 |
| --- | --- | --- |
| プロジェクトマネージャー | 進捗が見えず管理コストが高い | ダッシュボードで一目で状況把握 |
| チームメンバー | タスク抜け漏れが発生する | 通知・リマインドで漏れ防止 |
| 経営層 | 複数プロジェクトの状況が把握できない | 横断レポートで意思決定を支援 |

## 5. ビジネスモデル（概要）

- フリーミアム + サブスクリプション課金(詳細は[キックオフ資料](../03_kickoff/kickoff.md)の収益予測を参照)。
- プラン例：Free / Standard / Pro / Enterprise

## 6. スコープ（概要）

### 対象
- タスク管理、プロジェクト管理、進捗レポート、通知機能

### 対象外（将来検討）
- モバイルネイティブアプリ
- 他社サービス連携（会計、勤怠等）は次フェーズ以降
